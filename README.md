# PRODIGY_SD_03: Contact Management System

A desktop-based Graphical User Interface (GUI) system built using Python and Tkinter that acts as a local address book, allowing users to safely manage, review, and persist contact details.

## Features
- Full CRUD Support: Create, Read, Update, and Delete individual phonebook records.
- Persistent Data Storage: Automatically reads and writes records to a local JSON data engine format.
- Dual-Panel Interface: Dedicated side menus split field forms away from dynamic record navigation selections.

## Tech Stack
- **Language:** Python 3
- **GUI Framework:** Tkinter / TTK

## How to Run
1. Clone this repository or download the source code files.
2. Launch the desktop system context using the prompt:
   ```bash
   python main.py
   ```
